# Mode 3 데모 UX 개선 2차 — 체험 모드·상태 패널 화면 캡처

찍은 날: 2026-09-25 (KST). 설계: `docs/superpowers/specs/2026-09-25-mode3-demo-ux-phase2-design.md`.

```
npx hardhat node                          # :8545 (없으면 먼저)
node scripts/screenshot_mode3.mjs --tour  # 기본 출력 디렉터리가 이 디렉터리다
```

`--tour` 는 1차 세트(네 페이지 × ko·en·전문가, `results/mode3_ux_20260924/`)를 찍지 않고 **체험 모드** 네 장면만
찍는다. 스크립트가 격리 스택(`tests/helpers/isolated_mode3_stack.mjs`, **file 모드**, 임시 포트)을 스스로 띄우고
설치된 Chrome 으로 찍은 뒤 스택을 내린다. 개발용 :3100/:4100/:5100 은 건드리지 않는다. 넓은 창 1280px, `fullPage`,
한국어·전문가 보기 꺼짐.

찍는 동안 진행한 조작: 서비스 승인(헬퍼가 대행) → 서비스를 `?tour=1` 로 열기 → 지갑을 `?tour=1` 로 열기 →
지갑 등록(`12345`/`password123`) → 서비스 로그인 1회 → 상태 점 클릭.

## 파일

| 파일 | 언제 | 무엇을 보이려는 것 |
|---|---|---|
| `rp-tour-locked.png` | 지갑 등록 전 | 체험 모드가 켜진 서비스 페이지에서 로그인 버튼이 잠긴 모습 |
| `wallet-tour.png` | 지갑 등록 전 | 지갑 페이지의 말풍선(2단계)과 잠기지 않은 등록 버튼 |
| `rp-tour-bubble.png` | 등록 직후 | 서비스 잠금이 풀리고 말풍선이 3단계(로그인)로 온 모습 |
| `rp-stack-panel.png` | 로그인 뒤 | 상태 점 4개 + 펼친 상태 패널, 말풍선이 4단계(이용)로 이동 |

## 장면별 관찰 (실제로 본 것만)

- **`rp-tour-locked.png`** — 주소창 쿼리(`?tour=1`)는 지워지고 안내 바 오른쪽 "체험 모드" 스위치가 켜져 있다.
  (로그인) 카드의 **"로그인" 버튼이 회색으로 죽어 있고 그 오른쪽에 주황 배지 "먼저 지갑에서 등록하세요"** 가 붙는다.
  안내 바 아래에 다른 창 카드가 뜬다 — "2. 지갑을 등록하세요 / 지금은 지갑 창에서 진행할 차례입니다 / [다음 단계로]"
  (링크에 `?tour=1` 이 붙어 지갑 창에서도 체험 모드가 켜진다). 상태 점은 **신원 기관·서비스·체인 초록, 지갑 회색**
  (아직 미등록)이다. 단계 칩은 3 단계가 아니라 **2 가 현재**다.
- **`wallet-tour.png`** — 지갑 쪽에는 잠금 배지가 없다(서비스가 이미 승인돼 2단계 조건이 충족). 말풍선이
  "등록" 버튼 바로 아래에 앉아 "2. 지갑을 등록하세요 / 신원 기관에 한 번 등록하면 자격증명을 받습니다. 등록은
  계정당 한 번입니다." 를 보인다. 점은 서비스 페이지와 같은 조합(지갑만 회색)이고, 내 신원 카드에 "미등록" 배지가 있다.
  말풍선이 아래 (트랜잭션 보내기) 카드의 **제목 줄을 가린다** — 코치마크 성격상 의도된 겹침이고 누를 수 있는 요소는
  덮지 않는다(Task 3 보고서의 관찰과 같다).
- **`rp-tour-bubble.png`** — 등록 뒤 다음 폴링에 서비스의 **잠금과 배지가 사라지고** 로그인 버튼이 파랗게 살아난다.
  말풍선이 그 버튼 아래로 옮겨 와 "3. 서비스에 로그인하세요 / 이 서비스에서만 쓰는 주소로 로그인합니다. 신원 기관은
  어느 서비스인지 알지 못합니다." 를 보인다. 점 **넷 모두 초록**(지갑이 등록됨). 단계 칩은 1·2 가 done, 3 이 현재다.
  여기서도 말풍선이 (로그인 기록) 카드 제목을 가리지만 "새로고침" 버튼은 비켜 있다.
- **`rp-stack-panel.png`** — 로그인 성공 카드("✓ 로그인 성공 / 새 세션. 이 서비스에서만 쓰는 주소를 받았습니다.")가
  뜨고 말풍선이 **4단계("4. 세션을 써 보세요")로 옮겨 가 "세션 재검증" 버튼을 가리킨다**. 점을 누르면 안내 바 아래
  전폭으로 상태 패널이 펼쳐지고 네 줄이 보인다 — "신원 기관 정상 / 서비스 정상 / 지갑 정상 / 체인 블록 10".
  전문가 보기가 꺼져 있어 원본 JSON 줄은 나오지 않는다(켜면 역할별 JSON 이 붙는다 — Task 2 보고서).

## 남은 관찰 (고치지 않음)

- 말풍선이 대상 바로 아래에 겹쳐 떠서 **그 아래 카드의 제목 줄을 가린다**(지갑의 "트랜잭션 보내기", 서비스의
  "로그인 기록"). 설계상 배경막 없는 코치마크이고 누를 수 있는 요소는 피해 앉는다.
- 안내 바의 링크(`지갑 열기`·`신원 기관 관리자 열기`·`내 계정 페이지 열기`)가 1280px 에서도 두 줄로 접힌다.
  1차부터 있던 레이아웃이고 이번 범위에서 손대지 않았다.
- 6단계(폐기·복구)는 `--tour` 세트에서 다루지 않는다 — 게시까지 진행하면 다음 스크린샷이 폐기 뒤 화면이 되기 때문이다.
  6단계 판정의 알려진 비대칭은 `docs/MODE3_DEMO.md` 의 "체험 모드" 절에 적었다.
