```
npx hardhat node                        # :8545 (없으면 먼저)
node scripts/screenshot_mode3.mjs       # 기본 출력 디렉터리가 이 디렉터리다
```

스크립트가 격리 스택(`tests/helpers/isolated_mode3_stack.mjs`, **file 모드**, 임시 포트)을 스스로 띄우고 설치된
Chrome 으로 찍은 뒤 스택을 내린다. 개발용 :3100/:4100/:5100 은 건드리지 않는다. 찍기 전까지 진행한 조작:
서비스 승인(헬퍼가 대행) → 지갑 등록(`12345`/`password123`) → 로그인 1회 → 재검증 1회 → 트랜잭션 1건.
그래서 모든 결과 카드에 실제 내용이 들어 있다.

## 페이지별 관찰 (실제로 본 것만)

- **서비스(rp)** — 다섯 카드(서비스 상태 · 로그인 · 내 세션 · 로그인 기록 · 승인 개봉)가 2열로 앉고 넘침·겹침이 없다.
  로그인·재검증 결과 카드가 "✓ 로그인 성공 / 새 세션. 이 서비스에서만 쓰는 주소를 받았습니다." 처럼 한 줄 요약으로 뜬다.
- **서비스 · 전문가** — `#log`·`#sessionLog`·`#openLog`·`rpInfoExpert` 와 `skipSync` 체크박스가 나타나고, `자세히` 가
  펼쳐진 채 뜬다. 용어 라벨에 원래 기호가 붙는다(`AI 에이전트 허용 (allowAgent ∈ {0,1})` 등). 긴 JSON·root 가
  카드 안에서 줄바꿈되고 가로 스크롤은 생기지 않는다.
- **서비스 · 좁은 창** — 카드가 1열로 떨어지고 안내 바의 단계 칩이 여러 줄로 접힌다. 로그인 기록 표는 가로로 넘겨 읽는다
  (아래 "고친 것" 2). 표를 가로로 밀지 않으면 뒤쪽 열(공개한 조건 · AI 에이전트 · 작업의 "개봉 요청" 버튼)은 화면 밖이다.
- **지갑(wallet)** — 세 카드(내 신원 · 로그인 세션 · 트랜잭션 보내기). 등록 결과 카드에 AA 가 준 속성이 사람 말로 들어 있고,
  세션 카드에 "이 세션 끝내기(폐기)" 가 빨간 테두리로 뜬다. 속성 4칸은 읽기 전용이다.
- **지갑 · 전문가** — `#status`·`#sessionLog`·`#txLog`·`#intro`·`#chainInfo` 가 보이고 결과 카드의 `자세히` 가 펼쳐진다.
  세션 카드의 `dl.kv` 는 라벨이 길어져(원래 기호가 붙어) 값 칸이 좁아지고 주소·해시가 두세 줄로 접힌다 — 읽을 수는 있다.
- **지갑 · 좁은 창** — 공개 조건의 "최소/최대" 입력이 줄을 바꿔 앉는다. 가로 넘침은 없다.
- **관리자(admin)** — 다섯 카드(인증·최근 결과 / 계정 / 서비스 / 개봉 요청 / 폐기 목록). 시크릿은 `type=password` 로 가려지고
  결과·표 어디에도 나오지 않는다. 대기 배지가 "승인 대기 서비스 0 · 개봉 요청 0 · 대기 중인 건 없음" 으로 뜬다.
  파괴적 버튼(계정 폐기 · 게시)은 빨간 테두리다. 전문가 보기에서 "서비스 식별자"(arid) 열과 `#out` 이 더 보인다.
- **내 계정(account)** — 카드 하나(내 계정 폐기)뿐이라 화면 아래쪽이 비어 있다. uid·비밀번호·"내 계정 폐기"(빨강)와
  경고 두 줄. 전문가 보기에서 `#out` 한 줄이 더 붙는다.

## 이 점검에서 고친 것

1. `mode3/common/demo.js` — `Demo.setExpert()` 가 `applyI18n()` 을 부르지 않아 `data-term` 라벨이 토글보다 한 박자
   늦었다(전문가 보기를 껐는데 `(r_s, pk_i, max_height)` 같은 기호가 남고, 켰는데 안 붙었다). 첫 촬영분에서 드러났다.
2. `mode3/common/demo.css` — 폭 640px 이하에서 `table.list` 의 칸이 한 글자씩 세로로 접혀 읽을 수 없었다
   (`공/개/한/조/건`). 표 자체를 가로로 넘겨 읽도록 바꿨다. 넓은 창 레이아웃은 그대로다.
3. `scripts/screenshot_mode3.mjs` — 찍기 전에 맨 위로 스크롤한다. `#demoBar` 가 `position:sticky` 라
   스크롤된 채 `fullPage` 를 찍으면 안내 바가 페이지 한가운데에 박혀 카드를 가렸다(촬영 산출물 쪽 문제).

## 남은 관찰 (고치지 않음)

- 트랜잭션 결과 카드는 안쪽 호출이 revert 해도 "✓ 전송 성공" 으로 뜬다. `wallet.html` 의 `showTxResult` 가 `b.ok`
  (= `executed.success`)를 보지 않고 늘 성공으로 그린다. 이 캡처가 그 경우다 — 폼 기본값이 `AttrGate.claim()` 인데
  공개 조건 없이 보내 `success:false` 다(전문가 보기의 `자세히`·`#txLog` 에는 그대로 보인다). 트랜잭션 자체는
  성공한 것이 맞아 의도인지 확인이 필요하다.
- 지갑·서비스의 2열 배치에서 오른쪽 카드가 짧으면 아래가 비어 보인다(격자 행 높이). 기능 문제는 아니다.
