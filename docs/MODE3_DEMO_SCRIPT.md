# Mode 3 시연 순서 한 장 (snap 모드 · VM 분리 데모)

2026-11-14. 발표자가 따라가는 순서만 적는다 — 어느 탭에서 무엇을 누르고, 어디서 다시 로그인해야 하는지.
단계별 확인 포인트(어느 창이 떠야 하는지)는 `docs/MODE3_DEMO.md` 의 "수동 체크리스트(`snap` 모드)" S0~S18 이 정본이다.
이 순서는 코드와 격리 스택 화면을 근거로 썼고, **실제 MetaMask Flask 로 처음부터 끝까지 리허설해 확인한 것은 아니다.**

## 탭 — 이 순서로 열어 둔다

| # | 화면 | 주소 | 누구의 화면 |
|---|---|---|---|
| 1 | zk 스냅 화면 | `http://localhost:5100` | 사용자(스냅) |
| 2 | 속성 도구 | `http://localhost:5100/attr.html` | 사용자(브라우저 안에서만 계산) |
| 3 | zkID 내 계정 | `http://localhost:4100/user` | 사용자가 보는 IdP |
| 4 | zkID 관리자 | `http://localhost:4100/admin` | IdP |
| 5 | zkONE | `http://localhost:3100` (관리자 `/admin`) | 서비스 1 — 조건 없음 |
| 6 | zkTWO | `http://localhost:3101` (관리자 `/admin`) | 서비스 2 — 국가(한국·일본)·만 19세 이상 |

상단 바 색은 세 당사자가 같다. 탭을 옮길 때마다 "지금은 zkID 화면", "지금은 서비스 화면" 이라고 말로 짚는다.
관리자 비밀번호는 `scripts/demo_split_start.sh` 상단 주석의 `ADMIN_OPEN` 줄에 있다.

## 전날까지

1. 기동: `AUTO_APPROVE=1 TTL_BLOCKS=30 bash scripts/demo_split_snap_reset.sh` (코드를 고쳤으면 앞에 `SYNC=1`).
   - `AUTO_APPROVE=1`: zkONE·zkTWO 승인을 건너뛴다. RP 등록·승인을 보여 줄 때만 뺀다(`docs/MODE3_DEMO.md` "시연 순서(2026-10-22)" 1~2).
   - `TTL_BLOCKS=30`: 기본 5 는 세션이 몇 블록 만에 만료된다(자연 만료 시연용). Race (2) 를 하려면 늘린다.
   - 이 스크립트는 스냅 에이전트(:5100)·스냅 서버(:8082)·체인·VM 의 서버를 모두 내렸다 다시 띄운다.
2. MetaMask Flask 에 스냅 0.5.1 을 설치하고(1번 탭 "MetaMask 연결") "새로 만들기" → 백업 비밀번호 두 번 → "백업 파일 저장".
   - 백업 파일과 비밀번호를 손 닿는 곳에 둔다. 스냅을 MetaMask 에서 지우면 salt 가 지워지고, 되살릴 길은 이 백업뿐이다.
   - 파일 저장 창은 다운로드 폴더를 그대로 보여 준다. 화면을 공유한다면 저장 위치를 빈 폴더로 바꿔 둔다.
3. 처음부터 끝까지 한 번 돌려 본다. 로그인 한 번에 걸리는 시간을 재 둔다(이 문서는 재지 않았다).

**리허설을 반복할 때**: 리셋 스크립트를 다시 돌려도 스냅의 salt 는 남는다. 1번 탭 "내 계정" → "스냅 초기화"(등록만 지운다)를 누르고 아래 "본 시연" 1 부터 다시 한다. 스냅을 지우거나 다시 깔 필요가 없다. 같은 salt 이므로 auid 도 같다.

**시연 당일 하지 않는 것**: MetaMask 에서 스냅 삭제, "스냅 업데이트"(salt 가 남는지 실제 MetaMask 로 확인하지 못했다), 스냅 에이전트 재시작(모든 서비스 로그인이 끊긴다).

## 다시 로그인

- **폐기가 게시될 때마다**(누구의 폐기든) zkONE·zkTWO 의 열려 있던 로그인이 모두 닫힌다. 화면은 그대로 두고 내 자산 위에 "이 로그인은 닫혔습니다" 안내가 뜬다. 탭으로 돌아오거나 요청이 거절되는 즉시, 늦어도 10초 안에 뜬다.
- 다시 로그인하는 길: 안내의 "로그아웃하고 다시 로그인" → "로그인" → "zkID 로 로그인" → 아이디·비밀번호·auid → "로그인".
- auid 는 77자리다. 2 에서 복사한 값을 메모장에 붙여 두고 거기서 가져온다. 잃었으면 3번 탭 "내 정보" 의 auid 옆 복사 버튼.
- 안내가 뜨기 전에 출금·구매를 누르면 `세션을 다시 검증해야 합니다` 실패가 보인다. 오류가 아니라 같은 일의 다른 표시다 — 곧 안내가 함께 뜬다.
- 다음 단계에서 쓰지 않을 서비스는 다시 로그인하지 않아도 된다(예: 9·10 에서 zkTWO).

## 막혔을 때

| 보이는 것 | 할 일 |
|---|---|
| 팝업이 `스냅이 옛 버전입니다` 로 멈춘다 | 시연 중에는 고치지 않는다. 끝난 뒤 체크리스트 S15 |
| zk 스냅 화면에 탭 대신 "스냅 설정 — salt 와 백업" | salt 가 없다 — "백업에서 불러오기" → 백업 파일·비밀번호(체크리스트 S16) |
| 서비스 로그인이 `이 스냅은 이 IdP 에 이미 다른 계정으로 등록돼 있습니다` | 앞 리허설의 등록이 남았다 — 그 계정으로 로그인하거나, 리셋 뒤라면 "스냅 초기화" |
| Race (2) 에서 5블록 쪽도 통과한다 | 팝업 진행 줄의 "거울 상한" 이 `-` 인지 본다 — 게시·중계가 늦었다. 다시 로그인해 한 번 더 |
| 출금 팝업이 5분 넘게 멈춰 있다 | 서비스가 창을 닫고 `timeout` 으로 끝낸다 — 다시 누른다 |
| 로그인이 `expired` 로 끊긴다 | `TTL_BLOCKS` 가 작다 — 다시 로그인. 다음에는 `TTL_BLOCKS=30` 으로 띄운다 |
