인증 · 최근 결과

시크릿은 요청 헤더로만 쓰입니다. 화면·결과 카드·원문 로그 어디에도 남기지 않습니다.

이 탭을 닫으면 지워집니다(sessionStorage). 기본은 꺼짐입니다.

-

계정

등록된 계정의 속성을 고치고, 계정이나 로그인 세션 하나를 폐기합니다.

속성 4슬롯을 바꾸면 활성 자격증명이 물립니다(다음 게시까지 대기) — 지갑은 다음 발급에서 다시 받습니다.

"세션" 은 그 계정의 발급 세션 목록입니다. 활성 세션만 폐기할 수 있고, 폐기 리프도 되돌릴 수 없습니다.

관리자 시크릿을 넣으면 목록과 대기 건수를 불러옵니다.

서비스

승인하면 이 서비스 전용 추적 조각을 만들어 인증서를 냅니다. 거절은 되돌릴 수 없습니다.

관리자 시크릿을 넣으면 목록과 대기 건수를 불러옵니다.

개봉 요청

서비스가 올린 개봉 요청입니다. 승인하면 신원 기관 조각으로 봉인을 풀어 uid 를 기록합니다 — 대기 중인 항목에는 uid 가 없습니다.

복호 결과는 Poseidon(uid, arid) 라 등록부를 훑어 uid 를 되찾습니다(2026-09-18 §6.2).

관리자 시크릿을 넣으면 목록과 대기 건수를 불러옵니다.

폐기 목록

폐기는 덧붙이기만 됩니다 — 게시하면 되돌릴 수 없습니다(설계 §6.5).

하트비트(CIA_HEARTBEAT_BLOCKS)가 켜져 있으면 변화가 없어도 주기적으로 재게시됩니다.
